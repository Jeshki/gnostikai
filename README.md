# gnostikai

AEON — muziejaus lygio skaitmeninė gnostinių ir apokrifinių tekstų biblioteka. Lietuvių ir anglų kalbos, viešoji nuosavybė.

## Paleidimas

```bash
npm install
cp .env.example .env.local
npm run dev
```

Atverk [http://localhost:3000](http://localhost:3000).

DeepL raktas (`DEEPL_API_KEY`) reikalingas tik vertimo skriptams, ne svetainei.
